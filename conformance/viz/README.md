# Visualization conformance

The cases here pin `toMermaid` (TypeScript) and `ToMermaid` (.NET) to
[MODEL.md §9.1](../../MODEL.md). Each `<case>.json` is the input, and
`<case>.mmd` is the exact text every port must render for it. The comparison is
byte for byte, after normalizing CRLF line endings.

A case file holds:

| key | meaning |
|---|---|
| `spec` | A graph spec (MODEL.md §9). The harness builds it with a registry that maps every node type to a no-op. |
| `routers` | Optional. Code routers added after the spec's edges, as `{ "from", "targets" }`. `targets: null` means the router declared none. |
| `guards` | Optional. Hand-written guards (no declarative form) added after the routers, as `{ "from", "to" }`. |
| `options` | Optional. `direction`, `includeRouters`, and `highlight: { "next": [...], "pending": [...] }` as node names. |

Each harness renders the compiled graph. When a case has no `routers` or
`guards`, it also renders the bare spec, and both must equal the `.mmd`.

| case | exercises |
|---|---|
| `support` | the MODEL.md §9 shape: `eq` and `neq` predicates, START and END |
| `predicates` | every operator, `in` with mixed values, label escaping (`"`, `#`, `<`, `>`, backticks), `LR` |
| `escaping` | ids for names that are not plain identifiers (`fetch:docs`, `my node`, `çay`), Mermaid keywords (`end`, `Subgraph`), a generated id clashing with a real node `n0` |
| `routers` | declared targets including END, undeclared routers (`?` placeholders) whose ids avoid a node named `r0`, hand-written guards |
| `routers-hidden` | `includeRouters: false`, `BT` |
| `highlight` | `next` and `pending` classes, a pending node left out of `next`, duplicates collapsed, declaration order |
| `no-end` | no END node when nothing reaches it, an isolated node, a self-loop, a null name |

The `.mmd` files are generated by the TypeScript reference, reviewed by hand and
committed. Regenerate them only after an intentional change to the format:

```sh
cd ts/packages/core
node scripts/gen-viz.ts          # dry run: exits 1 if any file would change
node scripts/gen-viz.ts --write
```

Both suites pick up new cases on their own: drop in a `.json`, then generate its
`.mmd`.
